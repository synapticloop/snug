snug launcher runtime flow

What happens between a user double-clicking the built App.exe and Java main running — including the six JVM-discovery sources, the --download-jdk prompt, and every error short-circuit to the GUI dialog.

--download-jdk modes

off Discovery only.

If no compatible JVM is found in any of the six sources, launch aborts with JvmNotFound. The install dialog never appears.

auto Discovery first, prompt on miss.

Same six-step walk; only when all six return empty does the JDK install dialog appear.

force Skip discovery, always prompt.

Bundles a guaranteed Temurin install regardless of JAVA_HOME/registry state. Cancel still courtesy-re-runs discovery so a local GraalVM/Zulu isn't lost.

Error → UI surface

VariantSurfaceWhy
SelfPath, Format MessageBoxW Payload not yet decodable — no AppMetadata to read update_check_url from. Custom window can't be painted without it.
Io, NoMainClass, JvmNotFound, JvmTooOld, LibraryLoad, JniInit, JniCreate, JniAttach, JniInvoke, MainClassNotFound, NoMainMethod, JavaException error_window Custom-painted modal; localized via localize::t("err.*"); "Check for a newer version" link rendered from AppMetadata.update_check_url when present.
JdkError::* (metadata, sha256, extract, no_java_exe) error_window Same window, jdk.err.* keys. Failures inside the install flow don't strand the user — we courtesy re-run discovery before bailing.
Bare stub (no SNUGEMBD) stderr + exit 2 Not a real error — the user ran bin/launcher-stub.exe directly. CLI flags would have produced a real EXE; stderr message points at snug app.jar -o App.exe.

Quick reference

  • JAR cache: %LOCALAPPDATA%\snug\\\\app.jar
  • JDK install root: %LOCALAPPDATA%\snug\jdk\\
  • Per-launch log: %LOCALAPPDATA%\snug\\\\snug.log
  • Payload storage: SNUGEMBD magic + u16 version + u32 length + u32 CRC32 + postcard bytes — stored as RT_RCDATA resource, not binary overlay.
  • JNI version: hardcoded JNIVersion::V21 in the launcher — Java 25 boots fine via the V21 JNI ABI.
  • Splash lifecycle: shown after JNI InitArgs build, dismissed inside attach_current_thread (before find_class); Drop cleans up if attach never runs.

Source: crates/snug-launcher/src/main.rs, platform/windows.rs, jdk_install.rs, payload_locator.rs, error.rs. Mode semantics: crates/snug-format/src/lib.rs + crates/snug-cli/src/cli.rs.
